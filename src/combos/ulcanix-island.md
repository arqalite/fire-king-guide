# Ulcanix + Island

Usually you'll prefer to use any other starting hand if possible, but if Ulcanix and an Island is all you have, this will suffice.

In fact, if you don't care about [_Nibiru, the Primal Being_] safety, this is full Amblowhale combo (including Sanctuary!). However if you need to stay under Nibiru's threshold, then you'll have to settle for Princess + Arvata without Sanctuary, which means no Hyang on the opponent's turn.
