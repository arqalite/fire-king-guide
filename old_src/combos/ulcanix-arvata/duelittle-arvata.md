### Duelittle Chimera + Arvata setup (with Ponix in hand)

This is a cute endboard for a few reasons.

First of all, it challenges Nibiru - our endboard is done at the 5th summon exactly, and that summon is Arvata, which can negate Nibiru.

If Nibiru isn't activated, we pass on a fully set up Fire King engine, plus a monster negate. However we are vulnerable to a single [_Infinite Impermanence_] here, as we have no way to start our interruptions if Arvata is offline.

What's funnier is that this endboard **gets stronger** if Nibiru is activated - you negate with Arvata, destroying [_Duelittle Chimera_], which retrieves [_Fire King High Avatar Kirin_] from GY. This means we are no longer vulnerable to [_Infinite Impermanence_] as you can chain Kirin to destroy Arvata, starting the interruption chain.

Also, Ponix returns to hand in Standby Phase, giving you turn 3 plays.

#### Steps
- Normal Summon [_Fire King Courtier Ulcanix_].
- Activate Ulcanix; destroy [_Fire King Avatar Arvata_] and search [_Legendary Fire King Ponix_].
- Activate Ponix; Special Summon it from hand.
- Activate Ponix; search [_Fire King Sanctuary_].
- Activate Sanctuary; place [_Fire King Island_] in the Field Zone.
- Activate Island; destroy Ponix and search [_Sacred Fire King Garunix_].
- Activate Sacred; Special Summon it from hand.
- Activate Sacred; destroy [_Fire King High Avatar Kirin_] from Deck.
- Activate Kirin; Special Summon Arvata from GY.
- Link Summon [_Duelittle Chimera_] with Ulcanix and Sacred.

##### If Nibiru is activated
- Chain Arvata; negate Nibiru and destroy Chimera.
- Activate Chimera; add Kirin from GY to hand.
- Pass turn.

##### Opponent's turn
- In Standby Phase, activate Ponix to add itself back to hand.
